# Bab 10 - Overhaul v6

Bab ini merangkum apa yang berubah di v6 dibanding v5.2.2. Rencana aslinya ada di
`docs/PLAN-v6.md`; catatan serah-terima tiap fase ada di `docs/HANDOFF-v6.md`.
Bab 1-9 masih menjelaskan v5.2.2 dan belum ditulis ulang, jadi bila ada angka
yang berbeda, **bab ini yang berlaku**.

## 10.1 Struktur run: Act, boss, dan Endless

`FINAL_DEPTH = 10` sudah tidak ada. `DS.Acts` (di `src/core/rng.js`) mendefinisikan
**3 act x 10 depth**, lalu **Endless** setelah depth 30. Difficulty menjadi rumus,
tidak di-clamp (`src/systems/difficulty.js`); bioma berputar per act.

| Depth | Isi |
|---|---|
| tiap act, depth 5 dan 10 | boss (enam boss: Slime King, Stone Warden, Arbiter, Frost Wyrm, Lich, Magma Colossus) |
| sebelum boss | safe room (merchant, tanpa kutukan lantai) |
| 3 dst. | trial (22%, jeda 3 depth, tak pernah di depth boss) |
| setelah 30 | Endless: scaling terus naik, boss tiap 5 depth |

Armor musuh dibatasi supaya minimal 25% damage tembus; `biomeForDepth` untuk depth
Endless di-cache dengan batas 64 entri.

## 10.2 Worldgen

Tile hasil desain ditandai `designed` dan tidak dipilari `supportPlatforms`. Urutan
baru: rakit, edit puzzle/barrier/bonus/hazard, dukungan, `Reach.ensureExit`, lalu
pass anti-melayang terakhir. Solver (`npm run solve N`) sekarang menolak floor yang
punya `floatingRungs`, `orphanRopes`, `halfLadders` atau `pillarsInCorridor`.

Hasil terukur `npm run solve 50` (depth 1-30, semua tipe floor): **0 exit
tak terjangkau dari 1864 floor**, keempat metrik di atas **0**.

## 10.3 Render dan kamera

- **`DS.PostFX`** (`src/core/postfx.js`): SAO, god rays, bloom, color grading per
  tema, SMAA. F8 memutar kualitas low / med / high. Bloom dibatasi per sumber supaya
  matahari tidak silau.
- **Shadow map** dari key light; aktor melempar bayangan, tile menerima.
- **Kamera 2.5D** (`src/core/camfollow.js`, murni aritmetika, diuji di
  `tests/camera.test.js`): *grounded-Y follow*. Kamera mengikuti **jangkar** (tinggi
  terakhir hero berdiri), bukan hero. Lompat tunggal tidak menggeser frame sama
  sekali; double jump (puncak ~76 px) menggeser paling banyak ~15 px. Zoom dinamis
  hanya untuk boss dan musuh dekat, tidak lagi menurut kecepatan vertikal.
- **Horizon dikunci** satu ketinggian per level; hanya parallax horizontal.
  Pada floor pendakian, garis horizon *melayang* pelan setelah 2,5 detik di luar
  dead zone. Semua timer waktu-sim memakai `simDt` (selisih `g.frames`), bukan
  konstanta per panggilan render, jadi tetap benar di layar 30/60/144 Hz.
- **Backdrop = sumber cahaya**: `DS.Backdrop3D.heroInfo()` memberi posisi benda
  langit; key light directional diarahkan darinya (warna ikut sumber).
- **Obor**: api shader (`src/core/flame.js`), pool point light tetap
  (`src/core/torchlight.js`, jumlah light konstan sehingga shader tak dikompilasi
  ulang), peta cahaya baked untuk obor di luar pool, bara dan asap lewat FX3D.

## 10.4 VFX (`src/fx3d/`)

Partikel GPU ber-pool (`InstancedMesh`), ribbon trail, slash crescent, ring,
debris voxel, decal tanah. Combo nyata per senjata di `src/systems/combos.js`
(sword 3-hit, dagger, greataxe, spear, bow, staff; heavy = finisher sendiri).
**Element infusion**: tombol R/T memutar elemen senjata aktif di antara essence yang
terbuka dalam run. Ice field digambar biru jenuh separuh kuat (additive blending
di atas lantai pucat langsung menjadi putih).

## 10.5 UI HTML (`src/ui-html/`, `styles/ui.css`, `styles/hud.css`)

Satu design system (token warna, font, radius, animasi) dipakai HUD, menu, panel
dunia, dan UI in-world. `DS.HUI_ENABLED=false` atau `?huimenus=0` mengembalikan UI
kanvas lama. Perilaku yang dipertegas di v6:

- **Bar boss** muncul begitu boss *terlibat* (terluka, sedang bergerak, atau hero
  dalam 260 px), bukan saat boss sekadar ada.
- **Minimap** menyesuaikan jendelanya ke baris permukaan lantai, dan baris hero
  selalu berada di dalam jendela.
- **Angka crit** digambar lebih rendah dan lebih kecil supaya tidak menutupi nama
  elite; **kartu essence** punya gaya sendiri; **nama hero** hanya mengalah kalau
  chip prompt benar-benar menimpanya.

## 10.6 Animasi (`src/core/anim.js`)

Lapisan bobot tubuh, dijalankan **sekali per frame game**: jongkok lalu meregang
saat lompat, gepeng dan berdebu saat mendarat (makin keras makin pipih, volume
terjaga), kaki ditekuk di puncak lompat, condong ke depan saat dash, terhuyung saat
kena hit (sinyal `p.hurtFlash`, termasuk hit yang diserap shield), jatuh saat mati.
Musuh menekuk ke belakang saat wind-up (`DS.Enemies.windRatio`) dan pecah menjadi
kepingan voxel saat mati; hero juga pecah saat mati. Diuji di `tests/anim.test.js`.

## 10.7 Suara (`src/core/audio.js`)

Semua sintesis Web Audio; tidak ada berkas aset. `DS.Audio.play(nama, {vol, pitch})`
memberi detune acak per nama dan throttle per nama (kerumunan tidak menjadi noise).

| Kelompok | Suara |
|---|---|
| Senjata | ayun dan benturan per keluarga senjata; `swing()` / `impact()` memilihnya |
| Elemen | `elFire ... elWind` (8) dan `infuse` |
| Reaksi | `reactChain/Shatter/Explosion/Vortex/Steam/Bloom`, dipilih dari `FX3D.REACTION_STYLE` |
| Boss | satu raungan per boss lewat `roar(bossKey)` |
| Musuh | tanda serangan per jenis (`screech`, `growl`, `squish`, `rattle`, `telegraph`) |
| Dunia | `torch` (berderak makin keras bila dekat obor menyala), `landHard` |
| UI | `uiHover ... uiDeny`; `menuMove/menuPick/error` lama kini beralias ke suara UI |

`tests/audio.test.js` memastikan setiap nama suara yang dipanggil di `src/` benar-benar
terdefinisi dan berbunyi. `grab` dan `boom` ternyata dipanggil sejak lama tetapi
tidak pernah didefinisikan (diam); kini sudah ada.

## 10.8 Alat uji

| Perintah | Fungsi |
|---|---|
| `npm test` | 113 test (`node --test`), termasuk kamera, anim, audio, worldgen, kombo |
| `npm run solve 50` | solver reachability semua tipe floor depth 1-30 |
| `node tools/qa/probe-load.js` | boot halaman, cetak semua error console |
| `node tools/qa/shoot-phase6.js` | lompat (kamera/horizon diam), arah key light, obor |
| `node tools/qa/shoot-phase8.js` | squash/stretch, flinch, pecah saat mati |
| `node tools/qa/shoot-ui.js` | HUD, boss, safe room, shop, bag pada 720/1080/1440p |
| `node tools/qa/shoot-elements.js` | ground field tiap elemen |
| `node tools/qa/check-climb.js`, `check-hangs.js` | tali/tangga: bisa dipanjat, tertambat |

Skrip yang menggerakkan game dengan waktu nyata gagal palsu di mesin tanpa GPU
(renderer software jalan ~1 fps); skrip baru menjeda loop dan menjalankan simulasi
frame demi frame supaya hasilnya tidak bergantung kecepatan.
